# KoalaCartes

Cartes de fidélité, 100 % hors ligne (aucune permission Internet).

- Scan du code-barres à l'appareil photo ou depuis une capture d'écran
- Reconnaissance automatique du magasin (texte lu sur la carte + début du numéro déjà connu)
- Affichage plein écran, luminosité au maximum, pour la caisse
- Sauvegarde / restauration en fichier JSON

L'APK est compilé automatiquement à chaque envoi sur `main` et publié dans **Releases**.
